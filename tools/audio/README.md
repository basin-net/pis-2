# 音声台本の書き方

`tools/make_audio.py` は、ここにある JSON 台本から録音を作ります。

```bash
python3 tools/make_audio.py tools/audio/aud-62-004.json
```

声は macOS の読み上げ音声（または自分で録音した WAV）を使います。そこに次の加工が自動でかかります。

- **話し方の揺らぎ**：句ごとに高さ・速さ・大きさが少しずつ変わる。句読点の後に不規則な間が入る。声の高さと音量がゆっくり揺れる
- **人の音**：発話前の息継ぎ、口の音（ランダム）
- **部屋**：話者ごとの距離に応じた響きとこもり
- **テープ**：不規則な回転むら、呼吸するようなヒスノイズ、電源ハム、プチノイズ、音飛び、録音停止時の回転の落ち込み

作中では、ダビングした録音の声はすべて J-7 手続 96-4（話者マスキング）を通した、という設定です。読み上げ音声の平板さは、この「マスキング」として扱います。

## 全体

```json
{
  "out": "aud-62-004.wav",
  "note": "何の録音か（メモ）",
  "style": "reel",
  "seed": 62004,
  "lead": 0.8,
  "tail": 0.6,
  "stop": true,
  "room": {"size": 0.85, "wet": 0.22},
  "speakers": { ... },
  "beds": [ ... ],
  "timeline": [ ... ]
}
```

| 項目 | 意味 |
|---|---|
| `style` | `reel`（1960年代のリール）、`cassette`（1970年代のカセット）、`intercom`（施設の連絡回線）、`radio`（無線）、`line`（電話回線） |
| `seed` | 乱数の種。同じ値なら毎回同じ音になる |
| `stop` | `true` なら最後にテープの回転が落ちて止まる |
| `room` | `size` は部屋の大きさ（0.6〜1.2）、`wet` は響きの量 |

## 話者 `speakers`

```json
"PRUITT": {"voices": ["Nathan", "Grandpa"], "rate": 126, "dist": 0.45, "f0": 102, "vol": 0.8, "drift": 0.016, "shift": 0.98}
```

| 項目 | 意味 |
|---|---|
| `voices` | 使う声の候補。インストールされている最初の声を使う。Premium や Enhanced 版の声が入っていれば、そちらを優先する |
| `file` | 読み上げの代わりに使う録音 WAV（台本からの相対パス） |
| `rate` | 話す速さ（1分あたりの語数） |
| `dist` | マイクからの距離。0＝すぐ近く、1＝部屋の反対側 |
| `f0` | 咳やため息に混ぜる声の高さ（Hz）。男性 100〜130、女性 190〜220 |
| `vol` | 基本の声量（0〜1） |
| `drift` | 声の高さのゆっくりした揺れ幅。0.01〜0.02 |
| `shift` | 声全体の高さを変える倍率。1.2 前後で子どもの声になる |

## 背景音 `beds`

最初から最後まで鳴り続ける音です。`clock`（置き時計）、`fridge`（冷蔵庫）、`equipment`（機械のうなりとリレー音）、`traffic`（ときどき通る車）、`house`（家のきしみ）、`room`（部屋の空気音）。

```json
{"type": "clock", "gain": 0.035, "dist": 0.7}
```

## タイムライン `timeline`

上から順に並びます。

| 書き方 | 意味 |
|---|---|
| `["INT", "Who closed the door?"]` | 台詞 |
| `{"say": "INT", "text": "...", "gap": 0.2, "breath": false, "cut": 0.15, "gain": 0.8}` | 台詞（細かく指定）。`gap` は直前との間、`cut` は末尾を切る秒数（言いかけて遮られる） |
| `{"pause": 2.5}` | 沈黙 |
| `{"fx": "cough", "who": "PRUITT"}` | 人の音：`cough` 咳、`throat` 咳払い、`breath` 息を吸う、`sigh` ため息、`sniff` 鼻をすする、`lips` 口の音 |
| `{"sfx": "cup", "dist": 0.35, "gain": 0.4}` | 物音（下の表） |
| `"hold": true` | 次の音を待たせずに重ねる（足音を鳴らしながら話す、など） |
| `"offset": -0.1` | 位置をずらす。負の値なら前の音にかぶせる |

物音の種類：`cup`（カップを置く）、`token`（金属の札を盆に落とす）、`chair_creak`（椅子のきしみ）、`chair_scrape`（椅子を引く）、`chair_roll`（キャスター付きの椅子）、`paper`（紙）、`pen`（筆記）、`rustle`（鞄・布）、`steps`（足音。`"args": {"count": 3, "light": true}`）、`door_open`、`door_close`、`latch`、`clunk`（録音機のボタン）、`click`、`relay`、`squelch`（無線）、`car`。

### 台詞の中で使える記号

| 記号 | 意味 |
|---|---|
| `*word*` | 強調（少し高く、大きく、ゆっくり） |
| `_words_` | 小声 |
| `...` | 長いためらい |
| `--` | 言葉が途切れる、言い直す |

台詞を変えたら、同じページの transcript も必ず同じ内容に直してください。咳や物音は `[COUGHS]` `[A CUP IS SET DOWN.]` のように transcript に書きます。
