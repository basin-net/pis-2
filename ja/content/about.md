**PIS-2 // WICKER BASIN はフィクションです。** 非標準資産局、特別アクセス計画 WICKER BASIN、その施設、文書、録音、そこに名前の出てくる人物はすべて架空です。キューバ危機（1962年10月）などの実在の歴史的出来事は背景としてのみ登場します。実在の計画を描いたものではなく、実在の人物も登場しません。

SCP財団や Backrooms の流れをくむ共同創作ホラーで、1990年代の機密計画の内部ウェブサーバーという体裁で書かれています。ただしそれらとは違い、この組織は誰かを守ろうとはしていません。獲得し、阻止し、利用し、隠蔽します。

サイトは Git リポジトリ上のテキストファイルから生成されています。新しい文書は誰でも提案できます。リポジトリの `README.md` と `CONTRIBUTING.md` を参照してください。

**音声について。** 録音の声はコンピューターの音声合成です。物音、咳、ため息は Wikimedia Commons の録音（ほとんどがパブリックドメイン）を切り出して加工したものです。「Drag chair」「Drag chair 3」は Gravity Sound の作品で、CC BY 4.0（https://creativecommons.org/licenses/by/4.0/）で提供されています。出典の一覧はリポジトリの `tools/audio/samples/CREDITS.md` にあります。

**日本語版について。** このサイトは英語版の原典を日本語に訳したものです。録音の音声は英語のままで、各文書に書き起こしの日本語訳を載せています。英語の原典へは、各ページの「English」のリンクから移れます。
