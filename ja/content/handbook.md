(非機密) 本手引は、適格認定の際に全職員に配布する。本サーバー上のすべての文書の書式は本手引に従う。

## 1. 資産とは何か

非標準のものは、確保できるとき、またはその効果を再現できるときに**資産**として登録する。一度きりの出来事は、再発するまで**案件**（CR- または INC-）として扱う。「非標準」が正式な用語であり、「異常」「超常」などの語は用いない。

## 2. 指定番号の接頭辞

| 接頭辞 | 所管局 | 対象 |
|---|---|---|
| {m} BA- | B局 — 生物 | 生物とその組織。 |
| {m} MA- | M局 — 物品 | 物体と人工物。 |
| {m} PA- | P局 — 現象 | 条件、規則、繰り返し起きる出来事。 |
| {m} LA- | L局 — 場所 | 非標準の性質をもつ場所。 |
| {m} HA- | H局 — 人間 | 非標準の性質をもつ人物、および資産に曝露した人物。 |
| {m} CR- | J-6 | 相関報告：未確認の一般からの報告。 |

## 3. 格付け

すべての資産には3つの格付けを付し、クラス / 有用度 / 露見度 の順に記す（例：**IV / U4 / D0**）。

| クラス | 収容 |
|---|---|
| {ctr} I | 不活性、または完全に従順。標準的な取り扱い。 |
| {ctr} II | 物理的に危険。危険は通常の手段で管理できる。 |
| {ctr} III | 危険。挙動が完全には説明できない。二人制。 |
| {ctr} IV | 影響が物理的接触の範囲を超えて及ぶ。観察者にも曝露制限を適用する。 |
| {ctr} V | 収容が、管理者にも根拠の知らされていない手順に依存している。 |

| 有用度 | 国家にとっての価値 |
|---|---|
| {ctr} U0 | 負債。予見しうる用途なし。 |
| {ctr} U1 | 研究上の価値のみ。 |
| {ctr} U2 | 派生する物質や手法に用途がありうる。 |
| {ctr} U3 | 作戦での使用が実証済み、または見込まれる。 |
| {ctr} U4 | 戦略的。 |

| 露見度 | 一般に知られる危険 |
|---|---|
| {ctr} D0 | 自己隠蔽的。資産が自らの痕跡を消す。 |
| {ctr} D1 | 低い。 |
| {ctr} D2 | 中程度。民間伝承が存在する。 |
| {ctr} D3 | J-6 が措置を講じなければ露見する可能性が高い。 |

## 4. 状態コード

収容中 · 現地管理 · 監視中 · 未確認 · 喪失 · 封鎖 · **阻止済み**（外国による獲得を防ぐため破壊） · **放出**（意図的に解き放った） · **消費済み**（作戦または手順で使い切った）

## 5. 文書番号の接頭辞

INC- 事案 · EXP- 実験 · SUR- 調査計画 · FE- 実地評価 · WA- WICKER-APPLIED 提案 · ANL- 分析 · TR- 聴取記録 · AUD- 音声 · PSY- 心理 · NX- 解剖 · MC- 朝の計数 · FWO- 施設作業指示 · Q- 鎮静化案件 · K- HEADCOUNT の値

## 6. 閲覧権限

WICKER-1（計画の存在を知る者） · WICKER-2（支援要員） · **WICKER-3**（分析官、管理職員） · WICKER-4（サイト長、主任研究者） · WICKER-5（局長級以上）

{small} 注記（J-7）：CUSTODIAN の指定記号は、J-7 が管理するいかなる閲覧資格とも対応しない。「CUSTODIAN-7」は閲覧資格ではない。CUSTODIAN への適格認定の申請は受け付けない。

## 7. 用語集

| 用語 | 意味 |
|---|---|
| 消耗品(H) / (A) | 被験者。(H)は人間、(A)は動物。J-1 を通じて請求する。 |
| 志願者 | 同意書に署名した消耗品(H)。同意書には実験手順は記載されていない。 |
| 消費済み | 使い切られたこと。資産、物資、消耗品のいずれにも用いる。 |
| 相関報告 | 資産に関係する可能性のある一般からの報告（噂、投書、視聴者参加番組など）。J-6 に回付する。 |
| 残留痕 | 出来事の後に残る物理的または書類上の痕跡。 |
| 整合処理 | 出来事の後、公的記録同士が食い違わないよう書き換えること。 |
| 欠落分析 | 公的記録の中から、番号の飛び、空欄、説明のつかない数量を探すこと。一般社会で起きた PA-001 事案を検出する主な手段。 |
| 鎮静化 | 目撃者の管理。Q-1 観察。Q-2 信用失墜。Q-3 移住。Q-4 解決。 |
| K値 / K室 | PA-001 が働く床面積。その面積の部屋。K室は値に合致している間「有効」である。 |
| 積層化 | K室の定員を超えた者に起きること。6〜9秒かけて、骨の砕ける音と擦り潰す音を伴って床に押し込まれる。硬化するのは最上面だけで、元の床の性状になる。被験者はその下に、一人ずつ別の層として残る。 |
| 圧縮値 | K室の天井高の32分の1。床はこれより高くならず、代わりに古い層が圧縮される。 |
| 欠如感 | その者を知っていた人々が後に感じるもの。 |
| 無記名計数 | 名前を使わず、番号札で数えること。 |
| 朝の計数 | 全職員を毎日、数で数えること。 |
| 計数日 | 10月27日。全職員を対面で数える。 |
| 封鎖 | 指令 88-14 に基づくサイトの恒久的な閉鎖。 |
