分析 ANL-80-031                  極秘 // WICKER BASIN // 外国人開示禁止
J-2 分析部
件名：    PA-001（HEADCOUNT）：K値の起源。競合する仮説。
日付：    1980年04月14日

1. 問題は、なぜほかではなくこれらの床面積なのか、そしてなぜこれらの定員なのかである。当時知られていた29値に照らして、四つの仮説を検討する。

2. 仮説1 -- シェルター

   支持する点：
   a. 29値のうち24値で、定員は10平方フィートにつき1人に近い。1人あたり10平方フィートというのは、1961年以降の連邦公共核シェルター計画の計画基準値である。
   b. どの値も平方インチ単位で整数になる。フィートとインチで寸法を記した図面から算出した面積は、そうなる。
   c. 最初に記録された事象（K-01、INC-62-001）は、キューバ危機の最中に、指定された公共核シェルターで起きた。そのシェルターに掲示された収容人数は14人だった。K-01 の定員は14である。
   d. 発生は、建物の寸法をフィートとインチで定める地域に集中している。ソ連での発生頻度は米国のおよそ40分の1である。

   反する点：
   e. 低い値の存在。K-03（61平方フィートに0人）、K-07（418に2人）、K-04（140に3人）、K-12（198に6人）。シェルター調査で、418平方フィートに2人を割り当てたり、61平方フィートに誰も割り当てなかったりはしない。

   ただし：
   f. 低い値が、特定の機能を割り当てられた部屋であるなら話は別である。誰も入ってはならない記録室、高官2名の居室、要員3名の通信室、6床の医務室。その場合、これらの値は一般的な基準からではなく、特定の施設の特定の部屋についての計画から取られていることになる。

   評価：仮説1は規則的な値を説明する。(f) を加えれば低い値も説明する。ただし、この現象が特定の計画に従っていることが前提となる。

3. 仮説2 -- ソ連の装置
   支持する点：時期（1962年10月）。
   反する点：ソ連での発生頻度は高いのではなく低い。CANNERY 経由で渡った KARTOTEKA の資料（1977年）によれば、ソ連がこの効果を初めて記録したのは1964年であり、彼らはそれを UPLOTNENIE と呼んで驚いていた。
   評価：可能性は低い。

4. 仮説3 -- 遮蔽質量
   積層化された者は床に質量を加える。シェルターでは、質量が加われば中にいる者の防護が増す。この見方では、効果は「超過した者を遮蔽材に変える」ことになる。
   反する点：5mm の組織が床の防護係数を変える割合は1パーセントに満たない。また、遮蔽のためなら記録と記憶を書き換える必要はない。
   評価：魅力的ではある。記録への影響を説明しない。

5. 仮説4 -- 人口調査
   何かが人口を数え、それに上限を設けている。
   反する点：部屋より大きな規模での効果は観察されていない。
   評価：証拠なし。

6. 結論
既知のすべての値と矛盾しない仮説は、仮説1のみである。仮説1が正しければ、1962年10月かそれ以前に作成された部屋と定員の一覧表が存在する、あるいは存在したことになり、K値はその記載事項である。記録への影響もまた、その一覧表から来ているのかもしれない。

7. 勧告
1961〜62年の民間防衛および政府機能継続計画の記録を探索すること。まずは、当局がサイト1から引き継いで保管している資料から始める。

［押印：］SG-63 訓令 63-2 に基づき CUSTODIAN に回付。1980年04月18日。
［手書き：］措置不要。-- 局長  80年04月21日
