```doc
分析 ANL-79-014                  極秘 // WICKER BASIN // 外国人開示禁止
P局、J-1（医務）と共同
件名：    第3セルの床の高さ。層の圧縮。
日付：    1979年09月14日

1. サイト9 第3セルは K-03 である。寸法は7フィート0インチ×8フィート9インチ（61.250平方フィート）、天井高8フィート0インチ、定員0（[[applied|WA-66-01]]）。[[PA-001]]（第3項）によれば、この面積の床は被験者1人につきおよそ12mm（2分の1インチ）上がる。1966年から1979年8月31日までの使用実績は、計数で117。床は元の床版からおよそ1.44m（4フィート9インチ）の高さになっているはずである。

2. 実際の高さは 2-15/16インチ（75mm）である。

3. J-3 は1966年の初回以来、使用のたびに、扉を開けた時点と30時間後の2回、床を測定してきた。6人目の被験者までは、床は毎回およそ2分の1インチずつ上がった。それ以降は、どの測定でも 2-7/8〜2-15/16インチの間にとどまっている。それより高く測定されたことは一度もない。第3セルは防音されており、扉が閉まっている間はインターホンも切っているため、圧縮がどのような音を立てるのかは何も分かっていない。操作員は何も報告していない。

4. 8月20日、扉を開けたまま押さえた状態で、床を貫いてコアを2本採取した。どちらも厚さ1mmの表層の下に117枚の層がある。この数は使用実績の計数と完全に一致する。最上層は本来の厚さ（12mm）を保っている。その下では、各層が一つ上の層より薄くなっている。最下部の層は0.1mmに満たず、紙より薄い。顕微鏡で見ると、それらでさえ砕けた骨、軟組織、毛髪、乾いた体液からなる完全な薄板であり、上下を封じられている。他の層と融合した層はない。欠けているものもない。層は圧縮されたのである。

5. 値について。第3セルの床はおよそ3インチより高くはならない。これは天井高の32分の1である。

6. J-1 の研究 PSY-77-004 では、サイト3にある模擬事務室6室の床を、毎日そこで働く職員に知らせずに段階的に高くしていった。職員には毎週、部屋に何か変わったことはないかを尋ねた。部屋が「低くなった」「狭くなった」「何かおかしい」と初めて報告した高さの中央値は、天井高の32分の1だった。この研究は別の目的（改変された建物の J-6 整合処理）のために行われたもので、本分析が始まる前に完了していた。

7. 二つの数値は16分の1インチ以内で一致する。

8. 扉は考慮されていない。敷居の4分の1インチの段差は、またぐ者なら誰でも気づく。3インチの段差は台車を止める。圧縮値は、中にいる者に見え、感じられる部屋そのものに関わる。床の変化に気づかれた K室では、どの部屋でも、気づかれたのは扉のところだった。

9. 所見。積層化によって K室の床が天井高の32分の1を超えて上がるはずの場合、すでにある層が、音もなく、何も失われることなく圧縮され、床はその高さより下にとどまる。新しい層は本来の厚さのまま一番上に敷かれる。床の上昇は、積層化された者についての記録のうち、部屋に立つ者が知覚できる唯一のものである。それは知覚できる限度より下に保たれる。

10. 勧告。第3セルを掘削する必要はない。そのコアは正確な数を示しており、J-7 が WA-66-01 の使用実績を監査する際に用いることができる。
```
