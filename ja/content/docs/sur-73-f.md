SURVEYOR 計画 -- 最終報告        極秘 // WICKER BASIN // 外国人開示禁止
サイト9（「BRICKYARD」）                                  1973年06月30日

1. 目的
寸法を変えられる部屋、サイト9 第1セル、通称「アコーディオン」（電動の可動壁2面、位置決め精度128分の1インチ）を用いて床面積を走査し、K値を系統的に特定する。

2. 方法
アコーディオンの床面積を1平方インチ刻みで変えていく。各段階で、N 人の被験者を中に入れて扉を20秒間閉め、その後扉を開けて被験者を無記名計数で数える。値を検出できるのは、その定員が N 未満の場合に限られる。既知の値は扉を開けたまま通過する。第1セルは華氏68度±0.5に保つ。

3. 損耗
積層化された被験者（未返却の番号札）：312。これには確認走査（各値を2回ずつ確認）と、1967年9月の走査B再較正時の損耗を含む。消耗品(H)は全期間を通じて J-1 が供給した。

4. 所見
a. 17値を特定した。いずれも平方インチ単位で整数である。
b. 走査Cでは何も見つからなかった。700平方フィートを超える値があるとすれば、その定員は40以上である。これは10平方フィートにつき1人程度という定員と矛盾しない。
c. 走査した範囲内でも、定員が N 以上の値はこの方法では見つけられない。その数は不明である。

5. 勧告
打ち切る。残る値は、J-6 による公的記録の欠落分析で探すこと。
