```doc
P局
件名：    K-31 と SURVEYOR の記録
日付：    1986年02月03日

1. K-31（325.333平方フィート、定員0）は1985年3月19日に初めて記録された（[[INC-85-007]]）。

2. 325.333平方フィートは、SURVEYOR 走査A（40〜450）と走査B（40〜700）の範囲内にある。走査記録（[[SUR-73-F]]、附表）には、アコーディオンをちょうど46,848平方インチ（325.333平方フィート）にし、扉を閉め、被験者を中に入れた記録がある。

      1965年08月11日   N = 4    事象なし
      1968年06月14日   N = 12   事象なし

   定員0の値であれば、2回とも被験者全員が積層化されていたはずである。

3. 2-114号室は、1971年から1985年3月19日までの間に、扉を閉めた会議に2,214回使われ、事故は一度もなかった。

4. SURVEYOR の記録と本部別館2の予約簿が、同じ箇所でそろって誤っているか、さもなくば K-31 は1985年3月19日以前には存在しなかったかのどちらかである。

5. K-31 が1985年3月19日以前に存在しなかったのなら、K値は固定されていない。何かが値を追加できる。何かが、この建物のある部屋の寸法で、定員0の値を、その部屋で開かれる会議に間に合うように追加したのである。

6. 勧告
誰が、あるいは何が K値を追加できるのかを究明すること。

［手書き、欄外：］保管せよ。追及するな。 -- 局長
```
