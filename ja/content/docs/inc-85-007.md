```doc
事案報告 INC-85-007              極秘 // WICKER BASIN // 外国人開示禁止
日付：      1985年03月19日。発見 現地1310。
場所：      本部別館2、会議室 2-114
資産：      PA-001

1. 1310、2-114号室の扉が「引っかかる」との通報を受けて出向いた施設技術員が、扉が閉まった無人の室内を発見した。床には31人分の衣服と身の回り品があり、着ていた者たちがテーブルを囲み、壁沿いの椅子に座っていたかのような配置で置かれていた。テーブルにはコーヒーカップが14個。部屋は暖かく、いくつかのカップもまだ温かかった。

2. 2-114号室の床は、全体が均一におよそ 2-13/16インチ上がっている。床面を覆うカーペットは温かく、踏むと沈んだ（1330の時点で36℃）。同日1900には硬くなっていた。P局は積層化と確認した。真上の2-214号室にいた職員らは、0905ごろ、割れる音と擦り潰すような大きな音を聞いている。音は約20秒続き、記録上もっとも長い。音は隣の建物の工事によるものと思われた。報告を出した者はいない。1名が1100に J-3 に電話をかけ、保守係が床の工事をしているのかと尋ねている。

3. 部屋の寸法は20フィート4インチ×16フィート0インチ（325.333平方フィート）。これは既知の K値ではない。K-31 と指定する。定員は0と評価する。第6項を参照。

4. 欠員はない。3月20日の朝の計数（[[MC-85-03]]）を参照。

5. 会議室予約簿によれば、2-114号室は3月19日の0900〜1100に予約されていた。予約者名は空白である。予約簿によれば、2-114号室は本部別館2の開館（1971年）から1985年3月19日までの間に、扉を閉めた会議に2,214回使われており、事故は一度もなかった。

6. テーブルの上に署名簿があった（添付資料A）。31行が空白である。32行目には「立会人」と記されている。立会人がいて部屋を出たのであれば、K-31 の定員は0ではないかもしれない。3月21日、SG-63 を通じて CUSTODIAN に照会した。回答なし。3月25日に採取したコアには31枚の層があり、32行目の分の層はない（[[ANL-85-016]]）。

7. 本部別館2の定員表には、J-4（兵站・資材）の認可された役職が31ある。いずれも充足されていない。定員表によれば、充足されたことは一度もない。2-114号室は J-4 に割り当てられている。

8. J-1 医務によれば、3月19日から始まる週に、本部別館2の職員から「原因不明の悲嘆」による受診が47件あった。

9. 2-114号室は閉鎖（[[directives|指令 85-04]]）。作業指示 [[FWO-85-0412]]。3月25日、扉を開けたまま押さえ、J-7 の立ち会いのもとで床のコアを採取（[[ANL-85-016]]）。
```
