```doc
施設作業指示                                        FWO-85-0412
建物：      本部別館2
部屋：      2-114（会議室 -- J-4 割当）
依頼：      1985年03月19日 1420    依頼者：J-7（INC-85-007）
部屋の寸法（1971年竣工時。85年3月20日確認）：20'-4" x 16'-0"

作業内容
1. 床面が廊下の床よりおよそ 2-13/16インチ、全体に均一に高く
   なっている。原因：______________。研磨・撤去はしないこと。
2. 扉が床に当たっている。扉を外し、下端を3インチ切り詰めて
   吊り直すこと。
3. 両側に傾斜付きの敷居を取り付けること。
4. 31人分の衣服と身の回り品を回収し、袋に入れること。
   J-7（1-020号室）に届けること。仕分けはしないこと。
5. 鍵付きの錠を取り付けること（鍵は J-7 のみ）。
   「閉鎖中。使用禁止」の掲示を出すこと。

完了：      1985年03月22日

技術員の所見
床は今は冷たく、床版と同じくらい硬い。カーペットは見た目はカーペット
だが、叩くと石の音がする。毛足はまったく沈まない。そのままにした。
敷居のアンカー用に穴を開けた。カーペット越しに4分の1インチほどの
ところで、ドリルの刃が細かくざらついたものに入った。茶色の斑点と、
長い毛が何本か混じった白い粉が出てきた。J-7 に伝えた。作業を止めて
接着剤を使うよう指示された。
部屋には何のにおいもなく、粉もにおわなかった。カップ14個は洗って
J-4 の給湯室に戻した。J-4 のコート掛けにはフックが31本あり、
どれにも何も掛かっていない。
```
