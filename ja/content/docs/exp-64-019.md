```doc
実験報告 EXP-64-019              極秘 // WICKER BASIN // 外国人開示禁止
資産：    PA-001
部屋：    K-02 の複製（96.000平方フィート、定員9）、サイト9、第2セル
日付：    1964年02月17日
目的：    積層化された被験者の数を、事後に確定できるかを調べる。
被験者：  消耗品(H) 10名。[[x:12]] 軍刑務所より。
          入室時に、入室順に番号入りの真鍮の札（01〜10）を各自に交付。
観察者：  4名（制御室）。フィルムカメラ：2台。

1402:11  扉の掛け金がかかる。
1402:19  積層化完了。
         観察者（4名）は異常なしと報告。（第2セルは防音されている。
         マイクはすべての試験で切断している。）
1403:40  扉を開ける。計数した被験者：9。
1404:05  被験者から番号札を回収：01〜09。
1404:30  番号札10を床の衣服から回収。

試験後
- なぜ番号札を10枚交付したのか、説明できる観察者はいない。
- J-1 への請求書には「十（10）名」とある。請求したことを覚えている観察者はいない。
- フィルムのリール2には、10人の被験者が入室する様子が映っている。被験者10が誰なのか、特定できた者はいない。
- 番号札10とともにあった衣服は、刑務所の支給品ではない。私服のシャツとズボン、腕時計、そしてバッジの入っていないサイト9のバッジ留めである。
- 第2セルの床はおよそ8mm（16分の5インチ）上がった。表面は1404の時点で柔らかく温かく、翌朝には硬化し、元の封止コンクリートの仕上げになっていた。
- 第2セルが防音されたのは EXP-63-001（サイト1、開放型セル）の後である。この実験では居合わせた全員が過程の音を聞き、4名が異動を願い出た。J-1 は、今後いかなる操作員にも積層化の音を聞かせないよう勧告した。そのため、2月17日の操作員らは何も報告していない。

所見
この現象は名前を消す。数は消さない。名前を使わずに行った計数は残る。

勧告
PA-001 に関わるすべての作業に無記名計数を適用する。計画職員全員について、毎日、名前を使わない計数を行う。
1964年03月02日、指令 64-01 として採択。

注記（J-7、1964年03月04日）
指令 64-01 に基づき3月3日に行ったサイト9職員の初回の計数では、41名だった。サイト9の定員表は42の役職を認めている。欠員は記録されていない。制御室には椅子が4脚とコーヒーカップが5つある。
```
