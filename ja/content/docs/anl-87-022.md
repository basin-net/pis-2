```doc
分析 ANL-87-022                  極秘 // WICKER BASIN // 外国人開示禁止
P局、[[x:10]] 研究所（エネルギー省）と共同
件名：    層の分析、K-01（B-2号室、現地管理）
日付：    1987年06月22日

1. B-2号室の床を貫いて、扉の前、中央、奥の壁際の3か所でコアを採取した。B-2号室は1963年から賃借により現地管理しており、1962年10月27日以降、扉を閉めた状態で人が入ったことはない。どのコアも上から順に、厚さおよそ1mm の表層、厚さおよそ2mm の1枚の層、元の床版、という構成である。床は1962年当時よりおよそ3mm 高い。部屋の面積に換算すると、これはおよそ40リットルであり、体重35〜45kg の身体の体積に相当する。

2. 表層はセメントと細骨材である。その硬さ（反発度37）は、周囲の床版と2ポイント以内で一致する。組織は含まれていない。塗膜ではない。床のうち、床材であるのはこの部分だけである。その下面は、およそ0.5mm の幅で層に溶け込んでいる。

3. 層は4つの成分からなる薄板である。セメントは含まれていない。(a) 細かく砕けた骨。皮質骨と海綿骨の両方がある。破片はコア1本あたり数十万個で、0.1mm から3mm まである。破断面は新しく、治癒や風化の痕跡はない。(b) 軟組織。厚さ約0.2mm の暗褐色の革のような膜に押し延ばされ、破片をつなぎ合わせている。顕微鏡で見れば、皮膚、筋肉、脂肪を見分けることができる。(c) 毛髪。4〜38cm の長い暗褐色の頭髪で、毛根が付いている。(d) 乾いた体液（血液、血清、脂肪）。破片の隙間を埋め、すべてを褐色に染めている。層は乾いて固い。中のものは何ひとつ腐敗しておらず、においもない。破片は床全体にあり、どの採取点でも密度は同じである。破片の大きさは扉から離れるほど小さくなる。もっとも粗いものは敷居のところに、もっとも細かいものは奥の壁際にある。破片の長軸と毛髪は床と平行に横たわり、扉から放射状に広がる模様をなしている。癒合していない成長板と歯冠の破片から、死亡時の年齢は10〜13歳とされる。層は下面で床版に固着している。その構造は、K-31 の31枚の層のそれぞれと同じである（[[ANL-85-016]]）。

4. 骨、組織、毛根から DNA を抽出した。層は女性1名のものである。

5. R・D・プルーイット（シェルター管理人、INC-62-001）の対照試料は、1987年に医療を口実として入手した（Q-1）。

6. 結果：層の人物は R・D・プルーイットの子どもである。父子関係の確率は0.999を超える。

7. R・D・プルーイットに子どもはいない。郡の出生記録、1956〜62年の学校の在籍記録、1960年の国勢調査のいずれにも、プルーイットの子どもは記録されていない。1960年国勢調査のプルーイット世帯の調査票には、プルーイット，R・D（14行目）とプルーイット，M（15行目）が記載されている。16行目は空白である。次の世帯は17行目から始まっている。

8. 注記：案件ファイル 62-K-1 にばらで入っていた1963年2月4日付の回付票に、その少女のファーストネームが記されている。その文面は書き換えられていない。積層化された被験者の名を記した文書で、残存していることが分かっているものはほかにない。

9. 過程について。1962年の証人らは、割れる音と擦り潰すような音を数秒間聞いた。所見は、そうした音に見合うものである。身体は溶けることも、流れることもなかった。骨格は圧力によって次第に小さくなる破片へと砕かれ、破片は扉から床全体へと外向きに押し広げられた。軟組織と毛髪はそれとともに押し出されて破片の間に横たわり、体液もそれとともにある。粗いものから細かいものへの勾配は、彼女が扉のところで入ったこと、そして力がそこから伝わったことを示している。破片の長軸は、力がローラーのように下向きかつ外向きに押したことを示している。

力は床全体に均等に働き、目に見えるいかなる物体にも帰することができず、コンクリートに何の痕跡も残さなかった。表層は層の一部ではない。それは元の床版と同じ組成と硬さをもつ。層が敷かれた後に表面が作り直されたのか、層が表面の下に押し込まれたのか、どちらかである。我々にはそのどちらなのか判別できない。いずれにせよ、床は彼女を取り込み、それから彼女の上で閉じた。柔らかく温かい床という証人らの証言と、10月31日に見つかった硬い床は、自らを仕上げた床と矛盾しない。

これは ANL-80-031（仮説3）が想定した、受動的な質量の追加ではない。強制的な同化であり、その主体は部屋である。

10. 勧告：プルーイットとの今後の接触は行わない。
```
