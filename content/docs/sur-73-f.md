PROJECT SURVEYOR -- FINAL REPORT    TOP SECRET // WICKER BASIN // NOFORN
SITE 9 ("BRICKYARD")                                     30 JUN 1973

1. OBJECTIVE
Systematic identification of K-values by traversal of floor area, using a room of adjustable dimension: SITE 9 Cell 1, "the ACCORDION" (two motorized walls; positioning accuracy 1/128 in.).

2. METHOD
The Accordion is stepped through floor area in increments of 1 sq in. At each step the door is closed for 20 seconds with N subjects inside, then opened and the subjects counted by Blind Tally. A value is detected only if its occupancy is less than N. Known values are traversed with the door open. Cell 1 is held at 68 F +/- 0.5.

3. COST
Subjects laminated (tokens unreturned): 312. This includes confirmation runs (each value confirmed twice) and losses during the Pass B recalibration of SEP 1967. Consumables (H) were supplied by J-1 throughout.

4. FINDINGS
a. 17 values identified.
b. Pass C found nothing. Values above 700 sq ft, if any exist, have occupancy of 40 or more.
c. In the ranges swept, values whose occupancy is at or above N cannot be found by this method. Their number is unknown.

5. RECOMMENDATION
Terminate. Remaining values to be sought by J-6 Gap Analysis of public records.
